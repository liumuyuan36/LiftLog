# V1.12：先查证据，再决定模型分工

目标用户仍是需要可信训练记录与反馈的新手训练者。新增一般增肌知识问答，让用户在记录之外理解RIR、力竭、训练量等概念。当前没有真实用户需求、留存或付费验证，功能价值是假设。

## 产品与AI流程

用户问题 → 本机精简资料库检索 → 阅读来源 → 选择回答服务并确认 → 服务端重新检索 → 模型基于资料回答 → 格式/引用/数值校验 → 展示结论与原始来源。

资料为12条原创摘要，保留ACSM、研究摘要、NIH等出处与适用条件，产品规则单独标明。中文双字切词、BM25得分与主题词共同检索；不是向量库、没有新增Embedding费用，也不声称覆盖全部健身知识。小语料先采用可调试的简单方案，未来扩充时再检验检索召回、重排与分块策略。

Atlas和DeepSeek共用检索资料、Prompt与输出契约。Atlas是Qwen3-0.6B的记录LoRA；DeepSeek通过API调用，不涉及权重训练。经本轮对照，Atlas未通过问答门槛，公开页面暂不开放Atlas问答；DeepSeek问答仍需明确选择并确认。原有记录默认服务不变，不自动回退到付费模型。

## 为什么保留两类能力

前期训练与知识问答是不同任务：训练记录提取关心动作、日期、重量、次数及不确定性；问答关心证据相关性、条件与引用。记录任务的成功不能迁移为问答准确率，也不因问答实验失败就抹去记录能力与评测资产。模型分工以同题对照结果为依据，不以训练投入或模型名称为依据。

## 语音录入

本机录音/选择文件 → PCM WAV预览 → 单独同意上传DeepSeek ASR → 编辑核对文字 → 填入问题或训练描述。整理训练与保存仍需后续明确操作，不自动写入历史。当前最长60秒，文件不超过8MiB，客户端转为16kHz单声道16位PCM；服务端再次检查格式和时长。无音频落盘，无自动采集、上传或训练。

麦克风受HTTPS、用户权限和嵌入页面策略影响；文件选择与手机输入法作为替代入口。浏览器尺寸检查与合成音频验收不能替代iPhone/Safari/微信真机测试。

## 质量边界

引用ID有效不代表引用内容支持结论。程序校验只检查结构、来源集合与部分数值；语义支持与条件保留另行评分。资料不足、诊疗和个体处方问题由应用策略拒答，不能把这类免调用结果计入模型拒答准确率。问答失败保留问题和资料，无自动重试和格式修补。

同题实验见 `evaluation/knowledge/FROZEN.json`。8题与3项策略控制在预测前固定，预算上限1美元。全部问题与评分由AI编写，未独立人工审核，不代表真实用户准确率；费用按使用量和官方定价估计，账单以平台为准。

# V1.15.1 界面精简

本轮保留绿色与浅灰色视觉风格，减少首页、录入、规划、复盘与问答中的重复介绍和英文装饰文案。主要动作保留直接入口；数据口径、隐私细节和知识出处按需展开。

- 首页移除示例空间的重复引导与空模板占位，突出训练轨迹和训练助手。
- 一句话录入缩短说明与按钮，仍需明确同意后才发送文字；草稿仍须核对、确认完成并保存。
- 手机端四个助手标签排在一行，复盘操作放在事实卡片前方。
- 知识卡默认折叠；点击回答引用会展开对应卡片并跳转，适用范围与原始来源完整保留。
- 设置页折叠统计口径；数据备份、恢复风险提示和存储位置继续保留。

验证：143 项现有自动检查通过，源文件语法检查通过；320、390、430、1440 像素下 8 个页面共 32 项布局检查均无横向溢出。浏览器流程还检查授权前不调用模型、改写问题后取消旧授权、资料展开与引用跳转。截图均为内置合成示例，知识回答为 UI 模拟，不代表模型效果或真实用户测试。

# V1.15.3 单向蔓延

根据用户反馈，取消光点沿曲线前进或后退、选中节点循环呼吸和自动轮播详情。改为从起点一次铺开线条与淡淡边缘，沿途节点依次显现。进入首页自动展开一次，之后可主动点击「重新展开」。

当前段落的节点布局固定。点选历史记录只改变高亮和详情，线路不会缩回或重新展开；翻到段落之外的记录时直接展示新段，不做往返动画。展开过程不切换选中训练，也不写入记录。减少动态效果时立即展示完整路线；离开页面会取消动画帧。

143 项功能检查、32 项多尺寸布局检查与 8 项浏览器交互检查通过。[浏览器检查](browser-checks.json)记录单向进度采样、历史选择不回退、节点依次显现、减少动态效果、卸载与数据不变。

[实际界面动效预览](spread.png)使用独立浏览器中的合成示例录制，不代表真实训练或增肌成绩。训练比较、知识卡与模型权重均未更改。
